# BloxTacos — roadmap

## v0.2.0 (esta versão)
- Dois avatares GLB rigados: Noob R6 e Bacon Hair.
- Seletor de avatar com persistência local.
- Carteira local com 100 créditos Robux de demonstração.
- Catálogo com compra/equipamento de dez cosméticos.
- Classic Yard, Natural Disasters e Pizza Place locais.
- Chat visual clássico local.
- Workflow GitHub Actions para APK Android ARM64.

## Próximas versões
1. Melhorar prévias 3D de avatar e catálogo, com animações idle/walk consistentes nos dois rigs.
2. Importar mais modelos 3D de licença aberta para cenário, comida, ferramentas e móveis; manter arquivo de créditos por asset.
3. Adicionar NPCs de clientes, pedidos aleatórios, preparo e entrega com feedback visual na Pizza Place.
4. Criar mapa de Natural Disasters com mais eventos, efeitos visuais e objetivos variados.
5. Adicionar sistema de contas e salvamento em backend próprio.
6. Implementar multiplayer com sincronização de jogadores e chat com controles de segurança e moderação.
7. Criar editor de mapas e sistema de experiências publicadas.

## Princípios
- Usar modelos próprios, assets enviados pelo usuário ou assets com licença compatível.
- Não redistribuir arquivos proprietários do cliente Roblox.
- Manter a carteira de demonstração claramente separada da economia Roblox.
